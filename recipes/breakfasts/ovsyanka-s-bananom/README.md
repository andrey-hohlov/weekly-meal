# Овсянка с бананом

## О рецепте

- Приём пищи: завтрак
- Порций: 1
- Время приготовления: 5 мин

## Пищевая ценность на порцию

- Калории: 417 ккал
- Белки: 16 г
- Жиры: 13 г
- Углеводы: 59 г

## Ингредиенты

- Овсяные хлопья — 40 г
- Молоко безлактозное — 200 мл
- Банан — 100 г
- Арахисовая паста — 15 г

## Как готовить

1. Приготовить овсяные хлопья на 200 мл молока без добавления воды.
2. Переложить в миску.
3. Сверху выложить нарезанный банан.
4. Добавить арахисовую пасту и подать.

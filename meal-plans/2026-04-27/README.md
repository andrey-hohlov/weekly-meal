# Недельный meal plan

Понедельничный обед закрыт оставшейся с воскресенья 26 апреля 2026 порцией [Пасты с индейкой и томатным соусом](../../recipes/lunches/pasta-s-indeykoy-i-tomatnym-sousom/README.md).
Понедельничный ужин закрыт оставшейся с воскресенья 26 апреля 2026 порцией [Дорадо с картофелем](../../recipes/dinners/dorado-s-kartofelem/README.md).
Обычная гречка не используется. По явному запросу добавлена зелёная гречка как экспериментальная база для обедов. Брокколи из рецептов убрана.
Слабосолёная сёмга из домашней засолки идёт плотным блоком `пн-ср` на три завтрака [Тосты с лососем](../../recipes/breakfasts/tosty-s-lososem/README.md). 300 г сёмги хватит с запасом: по рецепту уходит 210 г, остаток можно добавить в эти же тосты более щедрым слоем.
Бананы собраны в блок `ср-сб` на четыре использования: два перекуса и две овсянки.
Обеды собраны по простой модели `база + мясо + овощи по умолчанию`: `вт-чт` [Тушёная говядина с зелёной гречкой](../../recipes/lunches/govyadina-s-zelenoy-grechkoy/README.md), `пт-вс` [Паста болоньезе](../../recipes/lunches/pasta-boloneze/README.md).
Ужины смещены по batch-логике без выбрасывания порций: [Курица с овощами и рисом на сковороде](../../recipes/dinners/kuritsa-ovoshchi-skovoroda/README.md) идёт `вт-ср`, [Фрикадельки из индейки с рисом и томатным соусом](../../recipes/dinners/frikadelki-iz-indeyki-s-risom-i-tomatnym-sousom/README.md) — `чт-пт`, [Форель с рисом](../../recipes/dinners/forel-s-risom/README.md) — `сб-вс`.

Средний день по неделе: примерно `2177 ккал`.
Средние БЖУ по неделе: примерно `Б 164 г / Ж 65 г / У 223 г`.
